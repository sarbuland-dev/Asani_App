# Asani test app: install guide (Android)

This is a **test version** called **Asani Dev**. It uses test data, so do not enter real medical details.
It needs **Android 8.0 or newer** and an internet connection.

## 1. Download the APK

1. On your Android phone, open the download link you received: `<download link will be added here>`
2. Download `app-dev-release.apk` (about 59 MB).
3. Only install the file from the link sent to you by the Asani team. Do not forward it.

## 2. Allow installing from unknown sources

1. Open the downloaded file (from the download notification, or the **Downloads** folder in your Files app).
2. If your phone says it cannot install unknown apps, tap **Settings**.
3. Turn on **Allow from this source** for the app you used to open the file (Chrome, Files or Drive).
4. Go back and tap **Install**.

Menu names differ a little between phones. You can also look in
**Settings → Apps → Special app access → Install unknown apps**.
On Xiaomi / Redmi, you may need to accept an extra warning before the switch turns on.

## 3. If Play Protect shows a warning

The test app is not on the Play Store, so Google may warn you.

1. Tap **More details** (or the small arrow).
2. Tap **Install anyway**.
3. If it asks to send the app for a security scan, you can choose either option.

If there is no **Install anyway** button, stop and send us a screenshot. Do not turn Play Protect off.

After installing, you can turn **Allow from this source** off again.

## 4. Log in with an email code

1. Open **Asani Dev**. Go through the intro (or tap **Skip**).
2. Type your email address and tap **Continue with email**.
3. Check your email for **Your Asani login code**. **Check the spam folder too.**
4. Enter the 6-digit code in the app. The code expires in 10 minutes.
5. First login only: fill in your profile, including your mobile number (one number can be used by one account only),
   agree to the Terms and Privacy Policy, and tap **Continue**.
6. If the app asks about notifications, allow them so you get queue alerts.

**No code?** Wait one minute, then tap **Resend code**. If it still does not arrive, or the email has a link but no
6-digit code, send us your email address and a screenshot.

## Reporting a problem

Send us: your phone model, Android version, what you were doing, and a screenshot.

## Installing a newer version

Open the new APK and tap **Update**. If Android says the app was not installed, uninstall **Asani Dev** first, then
install again.
